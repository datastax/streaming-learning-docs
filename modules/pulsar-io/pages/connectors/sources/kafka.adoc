=== Kafka source connector parameters (`configs`)

Set these parameters in the `configs` section of the connector configuration.

Generally, all properties provided in the https://pulsar.apache.org/docs/io-kafka-source[OSS {pulsar} Kafka source connector] are supported.
Exceptions include parameters that aren't relevant to {product}, and parameters that aren't present in {pulsar} {pulsar-version}.
