= JDBC SQLite
:connectorType: jdbc-sqlite

You can use the JDBC SQLite sink connector to stream data from {pulsar-short} topics into https://www.sqlite.org/index.html[SQLite] tables.

[#compatibility]
== Compatibility

SQLite JDBC is a library for accessing and creating SQLite database files in Java.

{product} supports {pulsar-reg} {pulsar-version}, which uses the https://github.com/xerial/sqlite-jdbc[Xerial SQLite JDBC 3.8.11.2 library].
