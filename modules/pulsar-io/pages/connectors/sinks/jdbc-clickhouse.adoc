= JDBC ClickHouse
:connectorType: jdbc-clickhouse

You can use the JDBC ClickHouse sink connector to stream data from {pulsar-short} topics into https://clickhouse.com/[ClickHouse] tables.

[#compatibility]
== Compatibility

{product} supports {pulsar-reg} {pulsar-version}, which uses the https://github.com/ClickHouse/clickhouse-jdbc[ClickHouse 0.3.2 library].
